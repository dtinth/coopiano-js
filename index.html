Inputs
  • Web MIDI: all connected MIDI inputs play the piano.
  • Computer keyboard (WebMIDICon piano keymap): bottom row Shift Z S X… and top rows ` Tab Q 2 W…. Alt plays the top rows one octave higher. Space is the sustain pedal. ←/→ transpose, ↑/↓ change octave, Esc–F12 set transpose.
  • WebMidiLink: load this page in a WebMidiLink host. It accepts midi,… messages through postMessage.
  • Web Audio Module 2: load wam/index.js in a WAM host, or try the test host.
